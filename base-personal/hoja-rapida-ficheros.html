Ficheros en Java

Hoja de consulta · java.nio.file · Acceso a Datos

¿Qué quiero hacer con el fichero?

Trampa 1. CREATE solo, sobre un fichero que ya existe, no lo vacía. Escribe encima desde el principio y deja restos. Comprobado: se escribió LARGO LARGO, luego corto, y el fichero quedó con corto y LARGO debajo.
Trampa 2. APPEND solo, sobre un fichero que no existe, lanza NoSuchFileException. Falta CREATE.
Sin ninguna opción equivale a CREATE + TRUNCATE_EXISTING + WRITE. Nunca se combinan APPEND y TRUNCATE_EXISTING.

Escribir muchas líneas

Se acumula en un StringBuilder y se escribe una sola vez, fuera del bucle. Si escribes dentro del bucle con TRUNCATE_EXISTING, cada vuelta borra lo anterior.

StringBuilder sb = new StringBuilder();
for (Alumno a : lista) {
    sb.append(a.getNombre()).append(";").append(a.getNota()).append("\n");
}
Files.writeString(ruta, sb);   // una sola escritura

Con Files

String todo = Files.readString(ruta);            // todo en un String
List<String> lineas = Files.readAllLines(ruta);  // un String por línea
for (String l : lineas) { /* ... */ }

Los dos lanzan IOException. O pones throws IOException en el método, o usas try/catch.

Con Scanner, línea a línea

try (Scanner sc = new Scanner(new File(ruta))) {
    while (sc.hasNextLine()) {
        String linea = sc.nextLine().trim();
    }
}

try-with-resources cierra el Scanner aunque haya excepción.

Procesar una línea nombre;nota

String[] partes = linea.split(";");
if (partes.length != 2) { /* línea malformada */ continue; }
try {
    String nombre = partes[0].trim();
    int marca = Integer.parseInt(partes[1].trim());
} catch (NumberFormatException e) { /* dato no numérico */ }

Orden de validaciones

  • Línea vacía
  • Número de campos tras split
  • Conversión a número, con try/catch
  • Rango, por ejemplo valores negativos

FalloArreglo

Varios Scanner(System.in) en el programaUsar uno solo y pasarlo, o declararlo static
"Suspenso" no coincide con "SUSPENSO"equalsIgnoreCase(...), o .trim().toUpperCase() antes de comparar

Letras donde iba un númeroCapturar InputMismatchException y hacer sc.nextLine() para descartar lo escrito
default del menú lanza excepciónMostrar "Opción no válida" y volver al menú
