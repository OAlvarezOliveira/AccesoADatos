2. Molde de un método DAO (JDBC)

  1. Escribir el SQL con ? donde van los datos (constante private static final).
  2. Abrir Connection y PreparedStatement en un try-with-resources.
  3. Rellenar los ?: setString(1, …), setInt(2, …). Se numeran desde 1.
  4. Ejecutar y, si es un SELECT, recorrer el ResultSet.

Escribir: INSERT / UPDATE / DELETE

public static boolean eliminar(int id)
        throws SQLException {
    boolean ok = false;
    try (Connection c =
             DriverManager.getConnection(URL);
         PreparedStatement ps =
             c.prepareStatement(SQL_ELIMINAR)) {
        ps.setInt(1, id);
        ok = ps.executeUpdate() > 0;
    }
    return ok;
}

Leer: SELECT

public static ArrayList<Tarea> listarTodos()
        throws SQLException {
    ArrayList<Tarea> lista = new ArrayList<>();
    try (Connection c =
             DriverManager.getConnection(URL);
         PreparedStatement ps =
             c.prepareStatement(SQL_LISTAR)) {
        try (ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                lista.add(mapear(rs));
            }
        }
    }
    return lista;
}
private static Tarea mapear(ResultSet rs) throws SQLException {
    return new Tarea(rs.getInt("id"), rs.getString("titulo"), rs.getBoolean("hecha"));
}
MétodoSe usa conDevuelve
executeQuery()SELECTResultSet: se recorre con rs.next()
executeUpdate()CREATE, INSERT, UPDATE, DELETEint: filas afectadas (> 0 = éxito)

Orden de un acceso JDBC: abrir conexión → preparar el PreparedStatement → rellenar ? → ejecutar → leer el ResultSet. Se cierra en orden inverso, y lo hace el try-with-resources.

3. SQL que se usa en los ejercicios

CREATE TABLE IF NOT EXISTS tarea(id INTEGER PRIMARY KEY AUTOINCREMENT,
                                 titulo TEXT NOT NULL, hecha INTEGER NOT NULL)
INSERT INTO tarea(titulo, hecha) VALUES(?, ?)            -- sin id: lo genera SQLite
SELECT * FROM tarea WHERE codigo = ?
SELECT * FROM producto WHERE LOWER(nombre) LIKE LOWER(?) -- setString(1, "%" + texto + "%")
UPDATE producto SET precio = ? WHERE codigo = ?
DELETE FROM tarea WHERE id = ?
SELECT COUNT(codigo), AVG(precio), MAX(precio), MIN(precio) FROM producto
SELECT categoria, COUNT(codigo) FROM producto GROUP BY categoria
  • URL de SQLite: jdbc:sqlite:archivo.db (se crea solo al conectar).
  • SQLite no tiene booleano: hecha es INTEGER (0/1). setBoolean y getBoolean convierten.
  • Una clave primaria repetida lanza SQLException: se captura en quien llama al DAO.
  • Los DAOs propagan la excepción (throws SQLException); Main y GestorFicheros deciden qué mostrar.

4. Ficheros de texto: lectura y escritura

Escribir con BufferedWriter

try (BufferedWriter bw = new BufferedWriter(
        new FileWriter(archivo))) {
    for (Producto p : lista) {
        bw.write(String.format(Locale.US,
            "%s;%s;%s;%.2f;%d", p.getCodigo(),
            p.getNombre(), p.getCategoria(),
            p.getPrecio(), p.getStock()));
        bw.newLine();
    }
} catch (IOException e) { ... }
  • new FileWriter(f) sobrescribe.
  • new FileWriter(f, true) añade al final.
  • Locale.US obliga a punto decimal. Sin él, en un sistema en español el decimal sale con coma y corrompe el CSV.

Leer con BufferedReader

try (BufferedReader br = new BufferedReader(
        new FileReader(archivo))) {
    String linea;
    while ((linea = br.readLine()) != null) {
        String[] campos = linea.split(";");
        if (campos.length != 5) {
            // línea mal formada: saltarla
            continue;
        }
        ...
    }
} catch (IOException e) { ... }
  • readLine() devuelve null al final.
  • read() devuelve -1 al final.
  • File.exists() comprueba si el fichero existe.

Importar una línea sin que un fallo aborte todo el bucle

try {
    Producto p = new Producto(campos[0], campos[1], campos[2],
                              Double.parseDouble(campos[3]), Integer.parseInt(campos[4]));
    ProductoDAO.insertar(p);
    insertados++;
} catch (NumberFormatException e1) { saltadas++; }   // subclase PRIMERO
  catch (IllegalArgumentException e2) { saltadas++; } // la superclase después
  catch (SQLException e3) { saltadas++; }             // un fallo del DAO no aborta el resto
// al terminar el while: imprimir el resumen (insertadas, actualizadas, saltadas)
  • NumberFormatException es subclase de IllegalArgumentException: el catch de la subclase va antes, o no compila.
  • Si el try ya no lanza una excepción comprobada (SQLException), capturarla en un multi-catch es un error de compilación: exception is never thrown in body of corresponding try statement.

5. Teclado con Scanner y menús

  • Lee todo con sc.nextLine() y convierte después: Integer.parseInt, Double.parseDouble, Boolean.parseBoolean.
  • No mezcles nextInt() / nextBoolean() con nextLine(): dejan el salto de línea en el buffer y el siguiente nextLine() lee una cadena vacía.
  • La variable del menú es local y se inicializa a -1 (con 0, un primer valor inválido cierra el programa).
  • Protege cada parseInt / parseDouble con catch (NumberFormatException e): avisa y vuelve al menú.
  • Cada llamada al DAO va en su propio try/catch (SQLException e).
